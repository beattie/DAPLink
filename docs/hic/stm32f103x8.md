# stm32f103x8 HIC

Based on STM32F103C8T6 chip ([Datasheet](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)):
- Cortex-M3 72 MHz
- 64 KB Flash
- 20 KB RAM
- Full-speed USB 2.0 device controller: up to 8 bi-directional endpoints including EP0 (*)
- UFQFPN48 packaging

(*) "Configurable number of endpoints from 1 to 8", "up to 16 mono-directional or 8 bidirectional endpoints can be used". (source: [RM0008](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf))

## Memory Map

| Region   |  Size  | Start       | End         |
|----------|--------|-------------|-------------|
| Flash    | 64 KB  | 0x0800_0000 | 0x0801_0000 |
| SRAM     | 20 KB  | 0x2000_0000 | 0x2000_5000 |

This variant is **interface-only** (no bootloader). The interface firmware starts at 0x08000000.

## Flash Layout

| Region       | Size  | Start       | End         |
|--------------|-------|-------------|-------------|
| Interface    | ~63KB | 0x0800_0000 | 0x0800_FC00 |
| Config       | 1 KB  | 0x0800_FC00 | 0x0801_0000 |

## DAPLink default pin assignment

Same as stm32f103xb variant. See [stm32f103xb.md](stm32f103xb.md).

## Features

Due to the limited 64KB flash size, this variant includes a **minimal feature set**:

**Enabled:**
- ✅ **CMSIS-DAP** - Debug protocol (HID and WinUSB/bulk endpoints)
- ✅ **CDC** - Virtual COM port for serial communication
- ✅ **WebUSB** - Web-based debugging interface
- ✅ **WinUSB** - CMSIS-DAPv2 driver-less bulk interface

**Disabled (to save flash):**
- ❌ **MSC** - No drag-n-drop flash programming
- ❌ **Drag-n-drop** - Flash programming must be done via debug protocol only

## Differences from stm32f103xb

The stm32f103x8 variant is designed for STM32F103C8 devices with 64KB flash, compared to the stm32f103xb variant which targets STM32F103CB devices with 128KB flash.

Key differences:
- **Flash size**: 64KB vs 128KB
- **Build mode**: Interface-only (no bootloader) vs Bootloader + Interface
- **Interface start**: 0x08000000 vs 0x0800C000
- **Interface size**: ~63KB vs ~79KB
- **HIC ID**: 0x9796990E vs 0x97969908
- **MSC/Drag-n-drop**: Disabled vs Enabled

## Building

To build the stm32f103x8_if project:

```bash
python tools/progen_compile.py -t make_gcc_arm stm32f103x8_if
```

The resulting binary will be located in the build output directory.
